Project Description

This Employee Management System is an academic project developed to demonstrate a full-stack web application. It allows users to manage employee records including adding, viewing, updating, and deleting employees. The system also includes department and role management with secure authentication.

Key Features
  • User Authentication & Authorization
  • Add, Edit, Delete Employees
  • View All Employees List
  • Department & Role Assignment
  • Responsive Design with Bootstrap
